# part-3-nlp-sequence-modeling
  # NLP and Sequence Modeling Mini Project

## Objective

The objective of this project is to build an NLP pipeline for customer support text classification and compare traditional vectorization methods with sequence-based deep learning models.

---

## Dataset

Customer Support Text Classification Dataset

Target Column:
- sentiment_label

Input Column:
- customer_message

---

## Tasks Performed

### 1. Dataset Understanding
- Record count
- Class distribution
- Average text length
- Sample text analysis

### 2. Text Preprocessing
- Lowercasing
- Removing special characters
- Tokenization
- Stopword removal

### 3. Text Vectorization
- TF-IDF Vectorization

### 4. Baseline Model
- Logistic Regression
- Accuracy evaluation
- Confusion matrix

### 5. Sequence Model
- Tokenization
- Padding
- LSTM Model
- Embedding Layer

### 6. Attention and Transformer Reflection
- RNN limitations
- LSTM advantages
- Attention mechanism
- Transformers in Generative AI

---

## Technologies Used

- Python
- Scikit-learn
- TensorFlow/Keras
- NLTK
- Pandas
- Matplotlib

## Results

The project successfully demonstrates:
- Traditional NLP pipeline
- TF-IDF vectorization
- Sequence modeling using LSTM
- Sentiment classification
